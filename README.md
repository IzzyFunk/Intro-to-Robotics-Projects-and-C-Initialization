# C++ Intro Workspace

## Overview
A foundational C++ project demonstrating local compilation, basic application logic, and build automation using CMake. 

## Environment & Dependencies
* **OS:** Ubuntu (Linux)
* **Language:** C++17 (or C++14 depending on your setup)
* **Build System:** CMake 
* **Compiler:** GCC / G++
